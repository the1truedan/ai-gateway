# Scientific IMRaD + ICMJE (public summary)

Use for **peer-review submission drafts** (caregiving AI / ACL / medical-adjacent).

## Section order (final manuscript)

1. Title · Authors · Affiliations
2. Structured abstract · Keywords
3. Introduction · Methods · Results · Discussion · Conclusions
4. References · Tables · Figures · Declarations

## Layout defaults (until journal template)

- 1″ margins, 12 pt body, double-space for many review drafts
- Named IMRaD headings; hierarchical H1/H2
- Tables editable; figures with captions + alt text for accessibility export

## Cite styles

Default pack suggests **AMA/Vancouver-style** via CSL; switch to APA/IEEE per venue.

## Not included

Full commercial style manuals; predatory-journal advice is author responsibility (ICMJE).
