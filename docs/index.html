how it came to be

Not a product pitch. A door that had to exist.

22 March 2026 — earliest vibecoding on record: surplus hardware, a homelab, long Grok threads. Hobby voltage.

13 April 2026 — the pivot. Real-world harm around a mother’s care made the hobby stop being a hobby. Within a week: an AI/ML certificate path, a caregiver prize track, and M.A.N.A.G.E.R. LLC (20 April). The question became: how do you prepare for the care when we cannot be there?

This repo grew as parallel infrastructure next to the caregiving monorepo. Desk Mac, GPU host, NAS — one OpenAI-shaped door so chat UIs and coding agents (Pi, OpenCode, Claude Code, Codex, Cursor, Grok Build) did not each invent their own base URL and their own outage.

Headroom went in front because stateless chats and paywalls were eating sessions. LiteLLM became the bus because every client already spoke that dialect. OpenRouter kept a free-model catalog alive so recon could stay cheap. Grok was both a coworker under the 31 July deadline and the thread that hopped twitter.com → grok.com → WebUI → local history ingest → this gateway. Hippo and PMB landed next so the door had a memory: hippo for what an agent explicitly remembered, PMB for what the repo already knew.

AgentsView is the session index — IDs and titles across Claude Code, Codex, Grok Build, OpenCode — not a transcript dump. It runs as its own compose stack so a chat-stack outage does not take the archive with it.

Then the weights outgrew every machine. The sibling fast-models pool (NVMe, Btrfs, bees, NFS) is the house behind the doorbell. Public trees are sanitized: no home secrets, no care records, no raw LAN IPs.

Fluke or project management — either way the boxes light up.

what this tree actually is

Glue and ops. The intelligence is upstream.

Compose, not a SaaS

Mac / Linux / NAS-shaped layouts. You bring keys, disks, and judgment.

Role routing

Plan on a strong model, recon on free or local scouts, execute locally when you can, keep care routes hard-local.

Fail early

Smoke scripts before a long agent session. A dead stack should fail in seconds, not an hour in.

Siblings

fast-models holds weights. mok-tua turns scripts into pictures. This repo is the door they share.
